## Goal

Repair the reported layout bug in the committed roadmap mockups: at desktop
width the filter panel claims the left column, the stage rail lands on the
right and the actual stages + Diagnostics fall below the viewport while the
center is blank; narrow widths show content. Root cause per human inspection:
common.css `.app` has 4 explicit rows while mockup `#fbar`/`#fchosen` lack
`grid-column:1/-1`, so auto-placement consumes the wrong cells, and the header
receives `.topbar` styles from chrome.js. Fix the shared mockup chrome and
regenerate all three committed variant HTMLs via the mockups build script -
never hand-edit the generated files. Do not touch the product dashboard.
